# Village Cart 🛒

A rural-focused e-commerce application designed for local grocery shops, featuring bilingual support (English & Odia), inventory management, and a customer-friendly shopping experience.

## 🚀 Live Demo

**[Visit the Live Application Here](https://ai.studio/apps/fffbda58-cc6d-4289-b165-850e80bb30f2?fullscreenApplet=true)**

## ✨ Features

* **Bilingual Support:** Seamlessly switch between English and Odia (ଓଡ଼ିଆ) for better accessibility in rural areas.
* **Dual Roles:** 
  * **Customer:** Browse products, manage cart, and place orders.
  * **Shop Owner (Admin):** Manage inventory, track orders, and view reports.
* **Rural-Specific Categories:** Tailored product categories like Grocery, Oil & Ghee, Paan & Puja, Cold Drinks, and Vegetables.
* **Real-time Updates:** Powered by Firebase for real-time inventory and order tracking.
* **Mobile-First Design:** Optimized for mobile devices with a clean, intuitive bottom navigation bar.

## 🛠️ Tech Stack

* React 18
* TypeScript
* Vite
* Tailwind CSS
* Firebase (Auth & Firestore)
* Framer Motion (Animations)
* Lucide React (Icons)

## 📦 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/tenacious7/Village-Cart.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
